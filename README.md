# T2T

This repository provides the implementation of **T2T: Captioning Smartphone Activities Using Mobile Traffic**.

*Jiyu Liu, Yong Huang, Yanzhao Lu, Yun Tie, Wanqing Tu*

Accepted by **IJCNN2026**

Please refer to our paper for more details.

## Setup

### Requirements
- Python ≥ 3.9
- PyTorch ≥ 1.10.0
- TorchVision ≥ 0.11.1
- CUDA ≥ 10.2

## Datasets

The collected video descriptions can raise privacy concerns. For ethical considerations, to access the T2T datasets, all users are required to complete a [Google Form](https://docs.google.com/forms/d/e/1FAIpQLSeYEXzkoRuObsYrXTlIHo7J72fG5tTcA-e-ewqksZjjs-_HHQ/viewform?usp=dialog) to confirm that the materials will be used solely for academic research purposes.

The datasets contain comprehensive traffic features extracted from real-world devices and their corresponding synchronized video descriptions, organized into the following structure:

- **Android Data:** `.csv` files containing features extracted from traffic collected on Android devices.
- **iOS Data:** `.csv` files containing features extracted from traffic collected on iOS devices.
- **Video Descriptions:** `.pkl` files containing descriptions generated by Qwen-VL-Max based on the synchronized recordings of user app usage.

Within each device-specific directory, the data is further categorized into five application types: `Messaging`, `Shopping`, `Video`, `Music`, and `Social Media`.

## Evaluation

We adopt four standard metrics for evaluating natural language generation: **BLEU-4 (B@4)**, **METEOR (M)**, **ROUGE-L (R)**, and **CIDEr (C)**.

**Note:** We have provided the standard evaluation code in the `utils/coco-caption` directory, which is identical to the source code from the [tylin/coco-caption](https://github.com/tylin/coco-caption).
